native clients exercise kernel/file mechanisms. They convey no A0 allocation,

* Channel: accepting a foreign process's kernel credentials, duplicate sequence,
  truncated frame or exported descriptor is red. Acceptance must require the
  still-live original birth/pidfd, and the parent's helper endpoint must be closed.
* Forgery: a capability-free fixture attributing explicit credentials to the
  retained parent must fail in the kernel, independently of receiver validation.
* Clock: delayed observation resetting the original issuance anchor/ends is red.
  Actual nsfs time and time_for_children descriptors must match, with a live pidfd.
* Profile: unsafe UID/capabilities/securebits must refuse the production seal.
  A synchronized filter leaving existing/new threads able to fork, use unchecked
  clone3, export the endpoint, change identity or enter namespaces is red.
* Publication: replacing/adopting existing final/staged names, publishing after
  expiry, accepting a symlink ancestor or accepting a replaced inode is red.
  Independent filesystem observations must match retained canonical bytes/inode.
* Partial writes: discarding the original inode/history, retrying the operation
  or repairing the staged prefix after a real file-size fault is red.
* Finite policy: changing V2 attempt end, extending intersected cutoffs, omitting
  unresolved declarations from close or admitting effects during JOIN is red.
