# NativeProbe SOURCE foundation

The current integration imports the indexed c10 mechanism bytes and adapts only
DATA decoding and its SOURCE checks. It has not been executed or qualified by
this integration. A request contains exactly allocationDigest/jobId/kind/machineId/
operation, uses sorted canonical JSON without LF, and authenticates nothing.
`nativeFoundationOnly` and installed/native/model/positive-terminal authority
remain unavailable. The original nondumpable helper association seam is open.

The three active hooks are `typecheck:native-probe`,
`typecheck:native-probe:root-source`, and `test:native-probe`. They use strict
inherited checks and explicit skipLibCheck=false. The native graph excludes
historical `bootstrap-source-checks.mts` and `delivery.mts`; those retained files
are inert provenance and must not run against the current source.

The contract harness reuses `scripts/rewrite-dist-esm-imports.mjs` only in its
owned disposable `dist` tree to resolve the existing core extensionless ESM
import. Its helper bytes join the checked-input inventory. Core source and the
workspace production dist are never rewritten by this harness. The isolated
Node24/Linux CI job runs the three hooks in root-owned protected TEST storage;
its outputs are SOURCE evidence only, with no runtime admission consequence.

This directory contains real Linux mechanism modules and a harmless owned native
contract client. `npm run test:native-probe` strictly typechecks the domain,
application, ports and MTS tooling, emits only into disposable temporary storage,
compiles C17 with warnings as errors against the already present stock libsystemd ABI,
and records exact check output plus the compiler source/type input graph SHA256
and verifies unchanged inputs through the run in workspace
`delivery/a0-native-probe`. Set `SR_NATIVE_PROBE_TMP` to a root-owned protected
TEST temporary directory; `/tmp` itself is deliberately not accepted as protected
publication ancestry. Fixtures and emitted trees are removed, never exported.

The C modules retain actual nsfs descriptors, pidfds, kernel per-message sender
credentials, original publication inodes and all protected ancestor descriptors.
The publication primitive uses the unchanged hosted slice/retention target names,
canonical nonexecuting fragment, exclusive staging and renameat2 NOREPLACE, file
and every ancestor fsync, and final named-to-held verification. Failures retain
partial custody until explicit owner disposal; invocation cannot repair/retry.
The synchronized helper filter denies process creation, unchecked clone3,
identity/namespace changes and endpoint export. The only clone path is the
explicit x86-64 libc thread flag profile. A failed fixed-identity/capability/
securebits/NNP check refuses the helper seal. A real Node consumer now exercises
this filter across existing V8/worker threads, a subsequent Node worker and the
libuv pool, on the actual inherited SEQPACKET channel. That fixture deliberately
has no FoundationOnly API and supplies no fixed-identity profile attestation.

The private resource adapter checks real cgroup-v2, the original retained
underlying delegation descriptor, empty internal domain nodes, CPU distribution,
all deterministic parent slices, actual cpu.weight=100 and paired original
cgroup-directory/events identities. A failed companion acquisition preserves the
original directory and ancestry. No ordinary file hierarchy can supply the view.

The finite stock sd-bus mechanism owns one original direct AF_UNIX connection,
manager birth/nsfs/pidfd association, bounded event inventory, original request
and reply objects/serials, buffered original job results, reload event association,
strict properties and unchanged InvocationIDs. Its fixed grammar uses transient
slice creation and fragment-backed target LoadUnit/RefUnit/StartUnit. Lost replies,
foreign mutation/events or capacity loss close dispatch; JOIN only processes the
original connection. Parent disposal is separate from helper/environment loss.
This module has compiled and its actual foreign-peer refusal was tested; no real
private stock manager resource operation has been run or qualified. Its remaining
owner/load-path/infrastructure admission dependencies prohibit public integration.
Stable ABI declarations use [stock libsystemd](https://github.com/systemd/systemd/blob/v257/src/systemd/sd-bus.h);
the test-only Node consumer uses [opaque Node-API](https://github.com/nodejs/node/blob/v24.8.0/src/js_native_api.h).
No dependency is installed, fetched or upgraded by the source harness.

These are private mechanism interfaces, not NativeProbe authentication. No public
FD/PID/token adoption interface or Source factory is supplied. Core policy contains
no Linux, systemd, filesystem, NAPI or provider mechanism. Core attempts retain
the existing V2 cleanup-attempt type and original epoch formula; native cutoffs
are separate, never substituted into that record.
The finite policy reserves a target slot at the first admitted Prepare branch,
before associating operation/intent identities or dispatching any step. Slots
remain consumed after completion, failure and observational JOIN. Exhaustion
closes admission with debt across the complete raw declaration inventory.
Successful in-flight acquisition after owner loss records acquired-then-lost
custody; ordinary closure retains handles while the owner remains live.

`npm run typecheck:native-probe:root-source` also checks the whole root source
without writing another owner's generated package output. It compiles the
existing pinned account-observability workspace package in disposable storage
and points a temporary compiler configuration at its actual emitted declarations.
Its temporary node_modules symlink resolves the workspace's configured type libraries.
The normal root check's required package build is preserved; no dependency,
source alias or production package configuration is changed. Historical predecessor evidence is separate; the current integration needs fresh
strict graph, actual C/Node contracts and root-source results.

A remaining native association boundary needs care: the current birth primitive
reopens the helper's proc namespace entries for live revalidation. Once the real
65532 helper is nondumpable and the executor excludes CAP_SYS_PTRACE, that proc
access cannot be assumed. The original owner must commit the actual retained
namespace objects together with the enforced immutable helper seal, then verify
that original association without reacquiring a protected process handle or
granting inspection rights. The current root-UID contract client does not prove
that future boundary. Source handoff stays unavailable until it is implemented.
