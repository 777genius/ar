# Security policy

## Supported version

This repository is an open-source Git mirror. Security fixes are applied to the
latest commit on `main`; package publication remains owned by the canonical
repository named in `package.json`.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/777genius/ar/security/advisories/new).
Include the affected revision, impact and reproduction steps. Do not open a
public issue for an undisclosed vulnerability, and never include credentials or
authentication files in a report.
